# Contributing to MCP-Agent-Accelerator

As we prepare for our public release, we welcome contributions from the core team.

## Getting Started

1. Ensure you have Node.js v18+ installed.
2. Install dependencies: `npm install`
3. Run tests to verify your setup: `npm test`

## Workflow

- Before starting significant work, please open an issue to discuss the proposed changes.
- Create a new branch for your feature or bug fix.
- Submit a pull request for review.

*This guide will be expanded before the public release.*
